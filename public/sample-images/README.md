# Sample images

Add the public demo images for the sample picker to this folder.

Supported extensions:

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`

Images are listed alphabetically at build time. Use a numeric prefix to control
the order, for example:

```text
01-batu-at-desk.jpg
02-batu-on-laptop.jpg
03-batu-by-window.webp
```

The filename becomes the visible label after the numeric prefix and extension
are removed. Rebuild or redeploy the app after adding or changing images.
